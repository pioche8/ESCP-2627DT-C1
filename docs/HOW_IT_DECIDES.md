# How TenderScout decides

Generated by `node shared/how-it-decides.js` from `engine.js` (d156c3a5078b) and `data.js` (69f99e355be5). Do not edit by hand: the same script feeds the website’s "How it decides" page, and CI checks that both outputs match the code. Every rule below was probed by running the engine; the weights and thresholds were read from it and verified by the probes.

The AI (simulated in this prototype) reads a tender pack and extracts requirements, each with the page, the original sentence and a confidence. This code compares those requirements with the company profile. Same input, same output; nothing here is a model.

## 1. Each requirement gets a status

| Status | Shape | Meaning |
|---|---|---|
| Meets | ● | the profile satisfies the line |
| Risk | ▲ | the line is not met but could be, so it costs half the points |
| Needs your check | ◆ | the AI is unsure; only the owner can answer, and until then the line counts nothing |
| Fails | ■ | a knock-out: the tender is No-go |

Before the typed rule runs, the AI’s confidence and the owner’s answer are checked:

| Condition | Status |
|---|---|
| AI confidence below 0.7 (70 %), no answer from the owner | ◆ Needs your check |
| AI confidence at or above 0.7 | ● Meets |
| the owner answered "We meet it" (whatever the confidence) | ● Meets |
| the owner answered "We don’t meet it" | ■ Fails |

Then the rule for the requirement’s type:

| Requirement | Condition | Status | What the app says |
|---|---|---|---|
| Minimum turnover | turnover at or above the minimum | ● Meets | Your turnover €1.5M ≥ €1.5M |
|  | turnover below the minimum | ■ Fails | Needs €1.5M turnover, you have €900k |
| Certificate | certificate held | ● Meets | You hold ISO 9001 |
|  | missing, subcontracting allowed | ▲ Risk | Missing ISO 27001. Subcontracting is allowed, so a partner could cover it |
|  | missing, subcontracting not allowed | ■ Fails | Missing ISO 27001 (mandatory) |
| Minimum references | enough references | ● Meets | 3 comparable references ≥ 3 |
|  | short by one | ▲ Risk | Short by 1 reference. A consortium partner could close the gap |
|  | short by two or more | ■ Fails | Needs 3 references, you have 1 |
| Bid language | language in the profile | ● Meets | Bid language German is covered |
|  | language not in the profile | ▲ Risk | Bid must be written in French. Translation adds effort |
| Place of delivery | a home country | ● Meets | You already work in DE |
|  | abroad, cross-border on | ▲ Risk | Work is delivered in ES, which is new for you |
|  | abroad, cross-border off | ■ Fails | Delivery in ES, and you do not take cross-border work |
| Mandatory site visit | always | ▲ Risk | Mandatory site visit: 20 Nov 2026, 10:00 |
| Anything else the AI extracted | always | ▲ Risk | Wording is vague. |

## 2. The fit score (0–100)

| Part | Points | How |
|---|---|---|
| Sector fit | 40 | 40 if any of the tender’s CPV codes starts with one of the profile’s two-digit divisions, else 0 (and the tender is No-go) |
| Size fit | 20 | 20 when the contract value lies between the profile’s minimum and maximum, 8 when it is smaller, 5 when it is larger |
| Requirements | 30 | 30 × (met + 0.5 × risk) ÷ number of requirements, rounded; a line that needs the owner’s check counts 0 |
| Time to prepare | 10 | 10 with 21+ days left, 5 with 10+ days left, 2 with 1+ days left, 0 on the deadline day |

## 3. The verdict

| Verdict | When | Score |
|---|---|---|
| Closed | the deadline is today or has passed (days left ≤ 0) | always 0 |
| ■ No-go | any requirement fails, or none of the tender’s CPV divisions is in the profile | capped at 25 |
| ● Go | score at least 70, no line needs the owner’s check, at most 1 risk | 70 to 100 |
| ▲ Maybe | everything else: a line needs the owner’s check, more than 1 risk, or a score under 70 | under 70, or higher with open lines |

Probe: with identical inputs the engine gives Maybe at 68 and Go at 70, and two risks stay Maybe at 85. Ranking: Go → Maybe → No-go → Closed, then by score, then by days left.

## 4. What the engine reads from the profile

| Profile field | Used for | Demo value |
|---|---|---|
| `turnover` | minimum turnover (euros) | €3.2M |
| `references` | minimum references | 4 |
| `certifications` | certificates (mandatory or via a partner) | ISO 9001 |
| `languages` | bid language | de, en |
| `countries` | place of delivery | DE, AT |
| `crossBorder` | place of delivery abroad | true |
| `cpv` | sector fit (the two-digit CPV division) | 32, 45, 51, 72 |
| `minValue` | size fit | €50k |
| `maxValue` | size fit | €1.5M |

Not read by the engine (display only): `name`, `city`, `staff`, `sectorsLabel`.

## 5. "Cites the page that proves it"

Every requirement the AI extracts is stored with the sentence it came from. For Landkreis Hohenau’s first line (Vergabeunterlagen, 64 pages, German):

| Field | Value | Shown as |
|---|---|---|
| `type` / `value` | `certification` / `ISO 27001` | the rule in §1 that runs |
| `label` | ISO 27001 information security | the line’s title |
| `cite` | p. 12, §3.1 | "Vergabeunterlagen, p. 12, §3.1" under the line and on the sheet |
| `src` | Der Auftragnehmer muss nach ISO/IEC 27001 zertifiziert sein. | the original sentence, quoted |
| `highlight` | nach ISO/IEC 27001 zertifiziert | the decisive phrase, underlined inside the quote |
| `tr` | The contractor must be certified to ISO/IEC 27001. | the translation |
| `confidence` | 0.95 | "95 % AI confidence"; under 70 % the line becomes "Needs your check" |

## 7. What is real in this prototype

- **Simulated:** reading tenders, translating, answering questions and drafting the profile (`ai.js`): pre-written output after a delay, labelled "Simulated AI" wherever it shows. No model is called and there are no keys.
- **Real:** this decision logic (`engine.js`), covered by 24 unit tests (`tests/engine.test.js`), 11 demo pins (`tests/demo-golden.test.js`), a seeded property test of 3000 random cases per run (`tests/engine-invariants.test.js`) and the 158 checks of the browser click-through (`tests/smoke.js`).
- **Fictional:** every company, buyer, tender, page number and quote (`data.js`). None of it is interview evidence.
