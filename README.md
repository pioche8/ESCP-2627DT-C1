## Run it
Mobile-first static web app: plain HTML, CSS and JavaScript, no build step, no dependencies.

- **Run locally:** open `index.html`, or `python3 -m http.server` and go to `http://localhost:8000`.
- **Light or dark:** the ◐ button in the header switches in one tap (persisted); Settings → Appearance (also behind ⓘ in the header) adds "System" (follow the phone). The app opens dark.
- **Reset the demo:** add `?demo=reset` to the URL, or Settings → Reset demo. **Live presentation:** `?demo=reset,fast` (or `?demo=fast` to keep your state) shortens the two simulated AI waits (profile draft, tender reading) to about 300 ms so the 75-second path in `BRIEF.md` fits; labels and output are unchanged.
- **Morning notification:** `?demo=morning` plays the simulated lock-screen notification once, then drops itself from the address; Settings → "Show this morning’s notification" does the same.
- **Moderated test:** Settings → Demo → "Copy test-session log" copies what happened on this phone. Nothing is sent, and Reset demo clears it.
- **Home screen:** in Safari, Share → Add to Home Screen once; the icon opens the app full screen at `?demo=reset,fast` (`BRIEF.md`).
- **Test-only URL options:** `?today=2026-12-23` shows the Closed state (deadlines passed); `?offline=1` shows the offline note; `?theme=system|light|dark` picks the appearance, same as Settings → Appearance. Without them the demo date stays fixed at Thu 5 Nov 2026 and the app opens dark.
- **Deploy:** repo Settings → Pages → Deploy from branch `main`, folder `/ (root)`. `.nojekyll` keeps Pages from running Jekyll over the repo (the `site/` and `design/` folders are served as plain files and ignored). Vercel: see [Website](#website) → Hosting.
- **Design tokens:** edit `shared/tokens.json`, run `node shared/build-tokens.js` (or `npm run sync` in `site/`), then `node shared/check-contrast.js`. The app's palette is nine colours per scheme (background, surface, ink, muted ink, brand and the four verdict colours); there is one radius (8 px), one typeface (Hanken Grotesk, tabular figures), and no gradients, shadows, alpha colours, grain, pills, eyebrows, uppercase, italics or negative tracking anywhere in the app. `tests/declutter-scan.js` proves it, for the app and the website. The website's motion timings sit under `siteMotion` in the same file and reach only the website.

### What's real and what's simulated
- **Real:** the decision logic. Change the profile (turnover, certificates, references, languages) and every verdict is recalculated by `engine.js`. Covered by tests.
- **Simulated:** anything a language model would do (reading PDFs, translating, answering questions). Marked "Simulated AI" in the UI. No API keys, no data leaves the phone.
- **Fictional:** every company, buyer, tender, quote and page number in `data.js`. Not evidence.
- **Real or fictional, figure by figure:** [`ARCHITECTURE.md` §9](ARCHITECTURE.md#9-what-is-real-and-what-is-fictional).
