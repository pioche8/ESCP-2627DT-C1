# design/

The designer's handoffs and reference pages, kept as they were delivered. **This is reference material, not app code:** nothing here is loaded by the app, and the website's build only copies photos from `assets/`. What ships today is described in [`../UI_DESIGN.md`](../UI_DESIGN.md), and its colours, type and radius come from [`../shared/tokens.json`](../shared/tokens.json).

**Which source wins** (from [`../docs/START_HERE.md`](../docs/START_HERE.md) §3): [`../DESIGN.md`](../DESIGN.md), then `HANDOFF_V2.md` and `MOTION.md` where they differ, then the 4 Nov declutter decisions in [`../CLAUDE.md`](../CLAUDE.md) §11 items 53–68. The engine and the data win over all of them. So several things drawn here were later removed from the app on purpose: the Sky and Harbor palettes (item 54), pills, glass, gradients and the mono typeface (items 53–66).

**Viewing the reference pages:** serve the folder (for example `python3 -m http.server`) and open a `.dc.html` file. They load React, Babel and Google Fonts from CDNs, so they need internet; the app itself does not.

`DESIGN.md` §11 lists files from the designer's original bundle (`TenderScout Renders.dc.html`, `TenderScout 3D.html`, `design_handoff_tenderscout_bold/`, `archive/`) that were never part of this repository.
